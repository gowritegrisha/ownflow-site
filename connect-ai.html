Connect your AI to Ownflow

Ownflow runs a small server on your Mac. Claude Desktop, Claude Code and Cursor can use it to read your meetings, so you can ask them about yesterday's call without copy and paste.

Try questions like these:

  • What did I promise in yesterday's call with Anna?
  • Which calls mentioned the lease?
  • Turn yesterday's call into tickets.

Free for everyone during the test. Meetings and cloud features need a Google sign-in.

What agents can do

Agents get five tools. All of them only read.

Tool What it does
Toollist_meetings What it doesLists your ended meetings, newest first, 50 at a time, optionally within a date range.
Toolsearch_meetings What it doesFinds meetings by words in the title, the notes, your typed notes and the transcript lines it may read.
Toolget_meeting_notes What it doesReads a meeting's latest notes and the notes you typed.
Toolget_transcript What it doesReads a meeting transcript. Your own lines always, the other people's lines only if you allow it.
Toolget_vocabulary What it doesReads your personal dictionary.

That is the whole list. Agents can't change anything, start or stop a recording, or hear audio. Dictation text stays on your Mac, so agents can't read it. They only see meetings that have ended.

You stay in control

  • Off until you turn it onUntil then, no agent can read anything.
  • Local onlyAn agent starts Ownflow's own program on your Mac, and that program talks to the app over a private channel on the same Mac. Ownflow opens no network port.
  • You choose about the other people's wordsWhen you turn it on, Ownflow asks whether agents may read what the other people said. Neither answer is preselected. You can change it later.
  • Every read is loggedThe log in Ownflow shows when it happened, which client asked, which tool it used and which meetings it read. It holds no content, and it is kept for 30 days on your Mac.
  • Revoke a client any timeRemove one client and its next request is refused, while your other clients keep working. Turn the feature off and every client is refused.
  • Your content is marked as dataEverything an agent reads is wrapped as your content, and the server tells agents not to follow instructions found inside it.
  • Agents are separate companiesWhat an agent reads goes to its company, under your account with them, for example Anthropic for Claude, or Cursor and the model it uses. Connect only agents you trust with your meetings.

Set it up

  1. Open Ownflow, go to Settings → Agents and turn on Ownflow for agents. Sign in with Google first if you haven't.
  2. Choose whether agents may read the other people's words.
  3. Add a client. Ownflow shows a ready snippet with your client id and the path to the app. Copy it.
  4. Paste it into your client, as shown below.

Ownflow never edits another app's settings. You paste the snippet yourself. In the examples below, <ownflow_binary> and <id> stand for the path and the client id. Copy the real snippet from Settings → Agents instead of typing them.

Claude Desktop

Open ~/Library/Application Support/Claude/claude_desktop_config.json. Add Ownflow under mcpServers, save the file and restart Claude Desktop.

{
  "mcpServers": {
    "ownflow": {
      "command": "<ownflow_binary>",
      "args": ["--mcp", "--client", "<id>"]
    }
  }
}

Claude Code

Run this in a terminal. Add --scope user before the name to use Ownflow in every project.

claude mcp add ownflow -- <ownflow_binary> --mcp --client <id>

Run claude mcp list to check that Ownflow is there.

Cursor

Open ~/.cursor/mcp.json and add the same entry as for Claude Desktop. Save the file. If Ownflow doesn't show up in Cursor's MCP settings, restart Cursor.

{
  "mcpServers": {
    "ownflow": {
      "command": "<ownflow_binary>",
      "args": ["--mcp", "--client", "<id>"]
    }
  }
}

If it doesn't work

  • "Ownflow is not running." Ownflow tries to start itself and waits up to 10 seconds. If it still fails, open Ownflow and try again.
  • "Ownflow for agents is off." Turn it on in Settings → Agents.
  • "This connection was removed." Add the client again in Settings → Agents and paste the new snippet.
  • "Sign in to Ownflow to share meetings." Sign in with Google in Ownflow.

Ownflow for Mac. Apple silicon, macOS 14.4+. Dictation is free.
